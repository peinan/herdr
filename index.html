# philosophy

既定は、本家のまま。

# opt-in by default

素の起動は upstream と同一

フォーク独自の UI はすべてスイッチ式。設定を書かない限り本家相当の見た目・挙動で、欲しい変化だけを config.toml で有効化する方針です。

# native detection

シェルフックなしで動く

ペインタイトルのプロセス名・cwd・git 情報は herdr 本体の syscall ベース検出から描画。.zshrc のフックや OSC 7 の設定は不要です。

# upstream-tracking

本家に追従し続ける

upstream/master を merge ベースで継続的に取り込み。差分は FORK_FEATURES.md に機能単位で記録しています。

[ui]

見た目を、細部まで。

各デモの設定値はクリックで切り替えられます。PR 番号はフォークリポジトリの Pull Request へのリンクです。

ui.pane_title_format

starship 風のペインタイトル書式

ペイン枠のタイトルを $変数 と条件付きグループで自由に記述。ディレクトリ・真のフォアグラウンドプロセス名・ペイン単位の git 状態(ブランチ / ahead-behind / dirty)を herdr がネイティブに検出して描画します。

  • 条件付きグループ ( … ) — 中の変数がすべて空なら、区切り文字ごと丸ごと消える
  • cwd・git は約 1.5 秒間隔で追従。cd や git checkout にフックなしで付いてくる
  • 同一リポジトリの別 worktree のペインも、それぞれ自分のブランチを表示
  • 優先順位: OSC タイトル > 手動ラベル > この書式。空文字なら従来挙動のまま

ui.tab_bar_{style,align,title}

タブバーを 2 系統から選ぶ

upstream の上部テキストタブ(classic)と、このフォークが導入したグリフ帯(minimal)を切り替え。minimal は寄せとタブ名併記をパラメータで調整できます。

  • classic: 自動採番・カスタム名・タブ多数時の横スクロールを持つ本家の見た目
  • minimal: タブバーの占有を 1 行のグリフ帯まで縮小。align / title で調整
  • tab_bar_position は upstream 共通キー(既定 "top")。classic にも効きます
  • align・title は minimal のときだけ有効(classic では常にテキスト)

[ui] popup

popup も、同じ手触りで。

キーバインドやプラグインが開くセッションモーダル端末にも、ペインと同じ余白とタイトル書式を。背景の塗り方と背後の減光も選べます。

ui.popup_{padding,title_format,background,dim_background}

透過ターミナルでも、崩れない

popup の枠と余白は panel 背景で塗られるので、端末を透過にしていると popup のまわりだけ不透明な帯が浮きます。塗る範囲を選べるようにしました。

  • popup_background — panel(枠と余白だけ・従来)/ all(内容の背後まで塗って不透明)/ transparent(どこも塗らず端末背景が透ける)
  • popup の中のプログラムが自分で塗った背景は、どの値でもそのまま残ります
  • popup_padding / popup_title_format はペイン側キーと独立。pane に余白を入れていても popup の見た目は変わりません
  • padding はサーバが決める PTY サイズとクライアントの描画矩形を同じ関数で一致させるので、popup 内の折り返しが崩れません
  • popup_dim_background — 背後を減光してモーダルらしく。all はサイドバーごと、panes はペイン面だけ

ついでに: 全角文字が枠線を食う不具合を修正

背景に日本語などの 2 セル幅文字があると、popup やモーダルの枠線がその行だけ消えていました。ワイド書記素が矩形の境界で半分だけ上書きされると、エンコーダが桁送りを誤って枠の 1 桁を描かなくなるためです。popup・全モーダル・トースト類・ペイン面のコピーまで、同じ修復を通しました。

[keys]

繰り返しは、prefix 一回で。

tmux の bind -r 風。prefix を押した後の一定時間は「アーム状態」になり、素のキーだけで同じ操作を連打できます。

[keys]
next_tab = { key = "prefix+n", repeat =  }
prev_tab = { key = "prefix+p", repeat = true }
repeat_timeout = 500  # ms — アーム状態を保つ時間

# repeat = true — タブ 3 つ先へ

⌃bnnnmain → agents → logs → build

# repeat = false — 毎回 prefix から

⌃bn→⌃bn→⌃bn

アーム解除は prefix / Esc / 未バインドキー / timeout 経過。対象はタブ・ペイン・ワークスペースのナビゲーションやサイクル系で、rename・help などダイアログに入る操作は repeat を付けても通常どおり一回で抜けます。#1

# install

手元で動かす

build & install
git clone https://github.com/peinan/herdr.git
cd herdr
make install  # → ~/.local/bin/herdr

ビルドには Rust toolchain と Zig 0.15.2(vendored libghostty-vt 用)が必要。make は mise で zig を用意します。mise を使わない場合は ZIG=/path/to/zig just build。

~/.config/herdr/config.toml
# 好きな行だけ書く — 書かなければ upstream と同じ
[ui]
tab_bar_style      = "minimal"
dim_inactive_panes = true
pane_title_format  = "$dir $process( ⋅ $branch$git_status)"
